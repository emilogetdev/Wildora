# Wildora 🌿
**Discover the wild world.**

Wildora is a responsive, beginner-friendly nature discovery web app.

## Included
- Explore starter guides for plants and wildlife
- Photo field-guide page with local image preview
- Outdoor inspiration cards
- Short nature facts
- Save discoveries in browser local storage
- Optional browser location permission
- Responsive layout for phones and desktops

## Run it
Open `index.html` in a modern browser, or enable GitHub Pages for this repository (Settings → Pages → Deploy from a branch → `main` → `/ (root)`).

## Current prototype limits
Photo selection currently previews the image locally; automatic AI species recognition is **not connected**. The outdoor cards are sample ideas, not live nearby search results. A maps provider and a safe species-identification service/API would need to be connected for those features.

## Privacy
Saved discoveries are stored in the browser on the device. The photo preview does not upload the selected image. Location is requested only after the user presses **Use my location**.
